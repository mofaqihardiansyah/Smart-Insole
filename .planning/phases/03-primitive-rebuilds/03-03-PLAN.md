## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| feedback state → assistive technology | The `role` a surface carries decides whether a clinical failure interrupts or waits; the decision crosses from a config module into two registers |
| legacy name → thirteen call sites | A delegate that changes behaviour silently rewrites every consumer at once |
| dictionary → shipped copy | A key present in one language only silently falls back to the other language |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07 | Spoofing | A failure surface that renders without `role="alert"` is announced late or not at all, so a clinician can miss a failure that looks like ordinary content | high | mitigate | `feedbackState.js` is the single decision; `AlertBanner.test.jsx` proves every tone's role from `roleFor`, proves both consuming registers read it, and plan 03-07 proves `StatePanel` reads the same function — so no surface can hold a private opinion about urgency. |
| T-03-08 | Repudiation | A missing next action leaves a reader with a cause and nothing to do, and nothing records that the half was absent | high | mitigate | Two-tier contract at the primitive: an `action` element or a `nextAction` string; a development warning when neither is present; a benign production fallback that renders the cause rather than blanking a clinical view. Plan 03-07 adds the call-site sweep over the repaired page. |
| T-03-09 | Information Disclosure | A second always-mounted polite region would re-announce live numbers continuously and drown the risk-level announcement | medium | mitigate | The primitive mounts its live element only while there is content to announce, declares no landing variant, adds no `aria-live` attribute of its own, and plan 03-07's live-region gate counts the polite regions so a second always-on one fails. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed by this plan (03-UI-SPEC.md:63-64). If a task ever needs one, the package-legitimacy gate applies and `[ASSUMED]`/`[SUS]` entries require a blocking human checkpoint; `[SLOP]` packages are forbidden. |
