## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| state vocabulary → rendered meaning | A chip's tone or level is a claim about a reading; an undeclared key rendered as the fallback makes a different claim convincingly |
| raised surface → text ink | The ink a label uses decides whether the label clears AA on the surface it actually sits on |
| tile content → tile box | A box that fixes its height clips the copy that carries the reading |
