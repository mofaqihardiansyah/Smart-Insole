<objective>
Restore the landing register's button variants and land the gate that makes their collapse impossible to repeat.

Purpose: the eight landing CTAs pass `variant="warm"` / `variant="warmOutline"`, neither of which `VARIANTS` declares, so `VARIANTS[variant] || VARIANTS.filled` (`GlassButton.jsx:61`) paints the app-register navy button at every landing call site. The hero's primary and secondary actions are visually identical, which `01-UI-SPEC.md:89` forbids. This is the defect shape of the codebase — a silent fallback that ships a wrong-but-plausible surface — so the fix and its gate ship in one commit (D-01).

Output: `warm` + `warmOutline` restored; `BUTTON_VARIANTS` exported as the declared key set; a shared `devWarn` helper; `src/variantKeys.test.js` failing on any undeclared literal `variant=` / `level=` call-site key; the press translate removed; four new test files.

This plan is the tracer for the phase's anti-silent-fallback posture: one call site → one primitive → one gate, wired end to end, before the same gate is widened by later plans.
</objective>
