## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → chart identity vocabulary | A page hands a chart a colour and a key; a mismatch between them silently mislabels which zone is which |
| categorical colour → clinical meaning | The donut's colour carries identity, the map's colour carries severity; conflating them re-encodes one meaning as another |
| chart window → drawn value | A buffer shorter than the window must not produce a value that was never measured |
