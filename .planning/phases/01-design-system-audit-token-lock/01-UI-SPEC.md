> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Motion (MOTION 1)

Permitted motion, each at or under 150ms unless noted:

- Colour, border, and single `scale-105` on hover and focus (state feedback).
- Heatmap danger-node pulse (draws eye to the point needing relief).
- Number transitions on value change (eye can follow the update).
- One scroll to the pressure map, only under `prefers-reduced-motion: no-preference`; jumps instantly otherwise.

Forbidden on app pages: scroll reveals, parallax, entrance animations, floating elements, `window.addEventListener('scroll')`, anything ignoring `prefers-reduced-motion`. Nothing is `100vh`; full-height sections use `min-h-[100dvh]`. No horizontal overflow at any width; nothing clipped at 200% zoom.

Landing motion budget (separate, disabled under `prefers-reduced-motion`): hero rise-in 420ms, scroll reveal 700ms (opacity + translate only, one IntersectionObserver), drifting headline tiles (one rAF loop), smooth scrolling. No WebGL, no parallax, no continuous rAF.

## Accessibility Contract

- Every text/background pair measured, never eyeballed (values in Color section).
- Every interactive target ≥ 44×44px on touch; 34–40px only from `lg`.
- Every interactive element keyboard-reachable and -operable, with a visible focus ring at 3:1 or better (`--focus` `#0F172A`, 2px outline).
- Risk never conveyed by colour alone: icon **and** text label **and** colour, always.
- Every data view has loading, empty, and error states; copy names the cause and the next action, never "No data".
- Live pressure numbers `aria-live="off"`; only a change in risk level is announced, through one `aria-live="polite"` region.
- `<table>` only rendered from `md` up; below that rows render as stacked definition rows.
- Mobile drawer is a real dialog: focus moves in, Escape closes, page behind cannot scroll, focus returns to trigger.
- Skip-to-content link + ARIA labels.
- Forms: labels above inputs, errors below in text; fields scroll into view above the on-screen keyboard.
- `prefers-reduced-motion` respected; `forced-colors` keeps status-chip and force-border shapes.
