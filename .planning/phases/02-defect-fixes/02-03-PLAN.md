## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| data source → data view | a view that misreports "no data" as "loading" tells a clinician to wait for something that is not coming; the state is a clinical signal, not decoration |
| colour → risk meaning | if colour is the only channel, a colour-blind or forced-colors reader loses the risk level entirely |
| component → caller | the tile tone is chosen by the page, so a decorative tint at the caller bypasses every visual review of the component |
