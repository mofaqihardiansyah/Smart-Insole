<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| render throw → user | an unhandled render throw unmounts the whole React tree, so the user's only signal is a blank page; the boundary is the sole control between a defect and a lost screen |
| thrown error → operator | a boundary that renders a fallback and reports nothing converts a visible failure into an invisible one, which is worse for a clinical instrument than a crash |
| dictionary → fallback copy | the crash surface ships strings like any other screen, so it must be inside the same parity and dash gates rather than bypassing them |
